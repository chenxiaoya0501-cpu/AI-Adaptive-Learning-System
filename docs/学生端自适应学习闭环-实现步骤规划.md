## 全局：学生信息隔离（贯穿所有步骤）

> 学生端是个人学习 OS：**A 学生不得读取或改写 B 学生的任何学情数据**。资产（知识点/题库/模板）只读共享；学情按 `user_id` 硬隔离。

### 隔离对象（学生域，按 user_id）

| 数据 | 说明 |
|------|------|
| 账号资料 | 手机号/邮箱、密码哈希、昵称等 |
| 学习目标 | `learning_goals` 及已学章节 |
| 测评与答卷 | `test_papers` / `test_attempts` / `test_answers` / 手写图 |
| 错题与 Tutor | `wrong_question_reviews` / `tutor_sessions` / `tutor_messages` |
| 画像 | `student_kp_mastery` / `student_ability_profile` / `diagnosis_reports` |
| 路径与课程进度 | `learning_paths` / `learning_tasks` / `generated_courses` 及完成状态 |

### 隔离规则（产品 + 技术）

| 规则 | 要求 |
|------|------|
| 鉴权 | 所有 `/api/v1/student/*` 必须带有效学生 JWT；无 Token → 401 |
| 归属校验 | 凡带资源 ID 的读写，服务端 **强制** `resource.user_id == current_user.id`；不匹配 → 404（防枚举） |
| 列表默认过滤 | 列表接口默认 `WHERE user_id = :me`，禁止「查全部学生」的学生端接口 |
| Schema 脱敏 | 答题未交卷：不返回答案/解析；响应中永不带其他用户 ID/联系方式 |
| 文件隔离 | 手写图等存 `uploads/student/{user_id}/...`；下载接口校验归属，禁止裸拼 URL 越权 |
| Admin 边界 | Admin 监控（S4）只读聚合/单卷回看走 **Admin 鉴权**，与学生 Token 分离；学生 Token 打不开 Admin API |
| 前端 | 本地草稿 Key 带 `user_id`（如 `draft:{userId}:{attemptId}`）；退出登录清空本机答卷草稿与缓存 |
| LLM | Prompt 只注入当前用户画像摘要；禁止把其他用户答卷送入模型；日志脱敏 |

### 验收（隔离）

- 学生 A 的 Token 访问学生 B 的 `goal_id` / `test_paper_id` / 手写图 URL → 一律失败  
- 两个学生同测不同卷时，报告/掌握度互不影响

**目标**：明确代码落在现有 monorepo 何处；学生端可独立打开、可登录；学情与资产读写边界清晰。

#### 0.1 代码目录落位（定稿 · 方案 C）

**单后端进程 + 前端按端拆分**。不新建第二套题库/知识点库；不设独立 `student/backend`。

```text
apps/
├── backend/                            # 【共享】原 apps/admin/backend
│   └── app/
│       ├── api/                        # 现有 Admin：knowledge / questions / …
│       │   └── student/                # 【新增】学生 Router，前缀 /api/v1/student
│       │       ├── auth.py / goals.py / tests.py / …
│       ├── models/
│       │   └── student/                # 【新增】学情 ORM（goal/test/mastery/…，含 user_id）
│       ├── schemas/student/
│       ├── services/learning/          # 【新增】组卷 / 批改 / 诊断 / 路径 / 课程
│       └── core/                       # get_current_student、归属校验
│
└── frontend/
    ├── admin/                          # 【已有】原 apps/admin/frontend，端口 5173
    └── student/                        # 【已建骨架】端口 5174，代理同一后端 :8000
        └── src/                        # pages: login / goals / exam / report / learn …
```

| 层级 | 放哪里 | 说明 |
|------|--------|------|
| 共享后端 | **`apps/backend`** | Admin + Student 同进程同库 |
| Admin 前端 | **`apps/frontend/admin`** | 教研后台 UI |
| 学生前端 | **`apps/frontend/student`** | 学生 Web；勿写入 admin 前端 |

| 资产 | 现有 knowledge/questions 表 | 学生侧 **只读** published；禁止学生 API 写资产 |

**本地开发约定**：

- 后端：`cd apps/backend && uvicorn app.main:app --reload --port 8000`  
- Admin 前端：`cd apps/frontend/admin && npm run dev` → :5173  
- 学生前端：`cd apps/frontend/student && npm run dev` → :5174

| 页面 / 状态 | 交互说明 |

### 第 2 步：动态出题（组卷算法 + 快照）

**目标**：在已学集合 \(L\) 上组贴近平均结构模板、又尽量均匀覆盖 \(L\) 的测评卷，并落不可变快照。

#### 2.1 产品交互方案（与现行 UI 对齐）

```text
目标列表「开始评测」→ /exam?goalId=
测评页 ExamHome
  ├── 当前目标摘要（年级 / 已学章 / 知识点）
  ├── 结构模板：读取管理端「平均结构模板」（题型题量/总分）
  ├── 选择题库：[真题库] | [模拟题库]   ← 对应数学题库两个题目列表
  ├── 主按钮 [开始诊断测评]
  │     → Loading 组卷（同用户防连点）
  │     → 成功：展示题目快照预览（无答案/解析）+ 写入历史
  │     → 降级：warnings 提示题源不足已调整
  └── 历史测评列表（仅本人、可按目标过滤）
```

| 场景 | 交互（现行） |
|------|----------------|
| 无目标 / 无已学章 | 引导创建目标或编辑勾章；组卷按钮禁用 |
| 选择真题 | `bank_type=real`，仅从 `questions.bank_type=real` 抽题 |
| 选择模拟题 | `bank_type=mock`，仅从模拟题库抽题 |
| 模板 | 优先考区默认 `ready` 平均模板；否则回退浙江 / 最近模板 |
| 组卷失败 | Toast 展示服务端 `detail`（如题池为空） |

#### 2.1.1 出题规则（需求定稿 · 2026-07-26）

1. **题库分流**：用户在测评页选择真题卷或模拟题卷；抽题池严格对应该库（管理端「真题题目列表 / 模拟题库列表」）。  
2. **结构模板**：参考试卷管理中生成的 **平均结构模板**（「查看平均模板」）：各题型 **题数与题型总分不变**。  
3. **知识点占比**：严格按模板 \(\pi(k,t)\)（`exam_kp_score_stats`，题型×主知识点分值占比）。  
4. **已学范围裁剪**：\(L\) = **当前年级阶段之前各册全部章**（如九年级上 ⇒ 自动含七上～八下）+ **本册用户勾选的章**；本册未勾选章及之后册次不出。  
5. **占比重归一**：未学知识点从占比中剔除后，对 \(L\) 内剩余占比 **同比例放大**（重归一），再混 \(\lambda=0.35\) 均匀覆盖项；用 Largest Remainder 落到整数题量。  
6. **落库快照**：`test_papers` + `test_questions`（含 answer/analysis，**响应不返回**）。

#### 2.2 技术交付与隔离

| 项 | 说明 |
|----|------|
| 模型 | `test_papers`、`test_questions`（`user_id` 硬隔离） |
| API | `GET /api/v1/student/tests/preview`；`POST /tests/assemble`；`GET /tests`；`GET /tests/{id}` |
| 算法 | `services/learning/assembly.py`（resolve 模板 → ˆπ → λ → Largest Remainder → 随机/借题） |
| 前端 | `pages/exam/ExamHome.tsx`；`api/tests.ts` |
| 隔离 | 越权 paper → 404；学生 Schema 无答案/解析；组卷锁按 user（进程内） |

#### 2.3 完成标准

| 标准 | 现行 |
|------|------|
| 真题/模拟分流抽题 | ✅ |
| 题型题数/总分贴模板；已学占比重归一 | ✅ |
| 快照落库；改题库不影响历史卷 | ✅ |
| 他人 paper_id 不可读 | ✅ |
| 进入正式答题页 | ⏳ 第 3 步 |

**默认参数**：诊断首测 \(\lambda=0.35\)；分值归主知识点；模板优先默认 ready，考区不足回退浙江。

#### 2.4 实现状态（2026-07-26 · 第 2 步已完成）

|----|------|
