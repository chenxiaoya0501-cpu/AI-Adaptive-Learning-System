# 学生端自适应学习闭环 — 产品方案细化（v0.2）

> **文档性质**：在《产品设计概述》与已建「知识库 / 数学题库」资产之上，细化下一阶段学生端闭环需求  
> **依据**：目标设定 → 动态出题 → 测试答题 → 阅卷批改 → 错题讲解 → 能力诊断 → 路径规划 → 动态课程 → 学习探索  
> **首期建议**：考试类型优先「中考」；科目优先「数学」；其它类型/科目做字段与接口预留  
> **状态**：方案确认稿（供产品拍板后拆开发任务）

## 0. 与现有资产的衔接

> **细化文档（产品 + 技术）**：[`与现有资产的衔接-产品与技术方案.md`](./与现有资产的衔接-产品与技术方案.md)

| 已有资产 | 本方案如何消费 | 本方案需补齐 |
|---------|---------------|-------------|
| 知识点库 `knowledge_points` / 关系 | 已学章节映射、出题覆盖、路径串联、课程目录 | 章节↔知识点更完整；掌握度字段在学生侧 |
| 数学题库 `exam_papers` / `questions` | 动态组卷题源、标准答案与解析、真题结构模板 | **题目强制关联知识点**；**真题分值/知识点占比统计**；模拟卷结构对齐 |
| 后台 LLM 配置 | 错题追问、OCR 后语义批改、Tutor | 学生端会话、认知画像入 Prompt |

**建设原则**：学生端不另起一套题库/知识点，统一读后台资产；每次测试在后台落「答卷快照」。

## 1. 总体闭环（用户 / 系统）

```text
用户：目标设定（可多目标）
        ↓
系统：动态出题（真题结构 + 已学知识点均匀覆盖）
        ↓
用户：测试答题（选择/填空/简答+手写图）
        ↓
系统：阅卷批改（含手写识别）
        ├→ 生成错题讲解（调题库解析 + 可追问 LLM）
        └→ 能力诊断 → 路径规划 → 动态课程生成
                ↓
用户：学习探索（提问 / 薄弱点动态练）
        └→（周期或主动）回到目标调整 / 再测 ────────┘
```

与总览文档一致：价值在「对当下最有价值的知识组织与交付」，本方案把「入学/阶段测评」明确为 **动态组卷 + 诊断** 的入口闭环。

## 2. 模块 1 — 目标设定

### 2.1 功能说明

用户登录后可创建 **多个学习目标**（如：中考数学冲 110；另存一个中考数学保 95）。任一时刻有一个「当前激活目标」驱动出题与路径。

### 2.2 字段模型（建议）

**LearningGoal（学习目标）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 主键 |
| user_id | string | 所属用户 |
| exam_type | enum | 中考 / 高考 / 职业教育 / 其它 |
| subject | enum | 数学 / 语文 / 英语…（首期数学） |
| target_score | number | 目标分数 |
| current_score_estimate | number? | 当前预估分（可选） |
| grade_stage | string | 年级阶段，如九年级上 |
| exam_date | date? | 考试日（可选，用于倒计时） |
| daily_study_minutes | number? | 每日可学时长 |
| learned_chapter_ids | string[] | 已学章节 ID 列表 |
| learned_knowledge_point_ids | string[] | 可由章节展开得到；允许用户微调 |
| region | string? | 考区，如浙江（影响真题模板） |
| status | enum | active / archived |
| is_primary | bool | 是否当前主目标 |
| created_at / updated_at | datetime | |

**Chapter（章节，可挂知识资产）**

- 与教材 `grade + chapter` 对齐；后台可用知识点上的 `grade/chapter` 聚合出章节树。
- 用户勾选「已学章节」→ 系统展开为知识点集合 \(L\)。

### 2.3 交互要点

1. 新建目标向导：考试类型 → 科目 → 分数 → 年级 → 已学章节（树形多选）  
2. 目标列表：切换主目标、归档、复制  
3. 变更「已学章节 / 目标分」→ 标记「需重测或重规划」

### 2.4 验收标准

- 同用户 ≥2 个目标可并存；切换主目标后组卷与路径读新目标  
- 已学章节为空时不可启动正式测评（可引导先勾选或走「入学全量测」例外策略）

## 3. 模块 2 — 动态出题（核心算法）

### 3.1 目标

在用户 **已学知识点集合 \(L\)** 上组一份测评卷，使得：

1. 题源来自对应科目题库（数学 → 数学题库）  
2. **题型种类、各题型题量** 与选定的「真题结构模板」一致  
3. **各知识点（或知识类别）在各题型上的分值占比** 尽量贴近真题统计  
4. 在约束下 **尽量均匀覆盖** \(L\) 中知识点  
5. 生成的整卷在后台落库（题目快照 + 答案 + 解析），可复现

### 3.2 前置：真题结构模板与知识点占比统计（后台必做）

#### 3.2.1 题目必须关联知识点

| 要求 | 说明 |
|------|------|
| 每题至少 1 个主知识点 | `primary_kp_id` |
| 可有次要知识点 | `secondary_kp_ids[]` |
| 组卷默认按主知识点计分归属 | 一题多点时，分值 100% 记入主知识点（首期简化） |

后台数学题库需补齐：批量标注、抽检覆盖率（未挂知识点的题不可入动态组卷池）。

#### 3.2.2 单套真题的「结构模板」

对每套已解析真题卷 \(P\) 统计：

**A. 题型结构**

\[
T_P = \{(t, n_t, s_t)\}
\]

- \(t\)：题型（choice / fill / answer / …）  
- \(n_t\)：该题型题量  
- \(s_t\)：该题型单题分值（若卷内同分）或题号→分值表  

若 Word 未带分值，首期用 **地区考纲默认分值表**（如浙江中考：选择 4 分×10、填空 4 分×6、解答题分值表…）挂到模板，并支持后台手工校正。

**B. 知识点（或类别）分值占比**

对卷内每题 \(q\)，分值 \(score(q)\)，主知识点 \(k=primary(q)\)：

\[
S_P(k) = \sum_{q: primary(q)=k} score(q),\quad
\pi_P(k) = \frac{S_P(k)}{\sum_{k'} S_P(k')}
\]

也可上卷到 **知识类别**（`domain` / `category_1`）：

\[
\pi_P(c) = \sum_{k \in c} \pi_P(k)
\]

**C. 题型 × 知识点 联合占比（推荐用于组卷）**

\[
\pi_P(k,t) = \frac{\sum_{q: primary=k,\ type=t} score(q)}{\sum_q score(q)}
\]

后台新增表建议：

- `exam_structure_templates`：由某套真题或「多套真题平均」生成  
- `exam_kp_score_stats`：模板下 \(\pi(k)\)、\(\pi(k,t)\)、题型题量  

**模板选择规则（首期）**

1. 按目标 `exam_type + subject + region + year` 匹配最近真题卷  
2. 若多套：对 \(\pi\) 与题型结构做 **等权平均** 得到「地区标准模板」  
3. 用户侧不可改模板；运营可在后台指定默认模板

### 3.3 组卷输入 / 输出

**输入**

- 激活目标 → \(L\)（已学知识点）  
- 结构模板 \(T,\ \pi(k,t)\)  
- 题池：`bank_type` 可配置（诊断卷建议优先 **真题**；练习可混模拟题）  
- 排除：近 \(N\) 次测过的题 ID（防重复）

**输出**

- `TestPaper`（测评卷实例）+ `TestQuestion[]`（**快照**：content/options/answer/analysis/score/kp 当时副本）

### 3.4 具体计算方案（可直接开发）

#### 步骤 0：可行域裁剪

1. 题池 \(Q\)：科目匹配、已挂主知识点、状态 published/reviewed、在 \(L\) 内  
2. 若某题型在 \(L\) 上可用题不足 \(n_t\)：  
   - 优先放宽到 \(L\) 的 **直接前置知识点**（图谱 prerequisite）  
   - 仍不足 → 该题型减少题量并记录 `degraded=true`，前端提示「已学范围题源不足」

#### 步骤 1：目标分值配额（题型 × 知识点）

试卷总分 \(S_{total}\)。对模板中的每个题型 \(t\)，该题型总分：

\[
S_t = n_t \times \bar{s}_t
\]

（或按题号分值表求和。）

在已学集合 \(L\) 上，把模板占比 **限制并重归一化**：

\[
\tilde{\pi}(k,t) =
\begin{cases}
\pi_P(k,t) & k\in L \\
0 & k\notin L
\end{cases}
,\quad
\hat{\pi}(k,t) = \frac{\tilde{\pi}(k,t)}{\sum_{k'\in L}\tilde{\pi}(k',t)+\varepsilon}
\]

题型 \(t\) 下知识点 \(k\) 的 **目标分值**：

\[
G(k,t) = S_t \cdot \hat{\pi}(k,t)
\]

若 \(\sum_{k\in L}\tilde{\pi}(k,t)=0\)（该题型在真题中考的点用户都没学）：将该题型配额 **均匀分给 \(L\)**（保覆盖）：

\[
G(k,t) = S_t / |L|
\]

#### 步骤 2：均匀覆盖修正（与真题占比的折中）

纯跟真题占比会导致 \(L\) 中「真题很少考到的已学点」永远抽不到。引入覆盖权重：

\[
G'(k,t) = (1-\lambda)\, G(k,t) + \lambda\cdot \frac{S_t}{|L|}
\]

- \(\lambda \in [0,1]\)：建议诊断首测 \(\lambda=0.35\)；阶段复测 \(\lambda=0.2\)  
- 意义：约 65% 跟真题结构，35% 强制均匀照顾已学点  

再把 \(G'\) 按题型内归一到 \(S_t\)。

#### 步骤 3：离散化为「各知识点应抽题数」

题型 \(t\) 单题分值 \(s_t\)（简化假设同分）：

\[
m(k,t) = \mathrm{round}\Big(\frac{G'(k,t)}{s_t}\Big)
\]

调整 \(m(k,t)\) 使 \(\sum_{k\in L} m(k,t) = n_t\)（最大余数法 / Largest Remainder）：

1. 先取 \(\lfloor G'/s_t \rfloor\)  
2. 按小数部分从大到小补 1，直到题量够  

得到整数配额矩阵 \(m(k,t)\)。

#### 步骤 4：选题（带约束的贪心）

对每个题型 \(t\)、每个知识点 \(k\)，在候选集

\[
Q(k,t)=\{q\in Q:\ primary(q)=k,\ type(q)=t,\ q\notin Recent\}
\]

中选 \(m(k,t)\) 道：

**选题得分（越大越好）**

\[
\mathrm{score}(q) =
\alpha_1(-\mathrm{times\_used})
+ \alpha_2(-\mathrm{recent\_gap}^{-1})
+ \alpha_3 \cdot \mathrm{difficulty\_fit}(q)
+ \alpha_4 \cdot \mathrm{quality}
\]

- `difficulty_fit`：首测靠模板卷均难度；复测略偏向薄弱点难度（诊断后启用）  
- 同知识点多题时尽量选不同 `secondary` / 题干指纹，降低同质  

若 \(Q(k,t)\) 不足：从同 `category_1` 且 ∈\(L\) 的邻近知识点借题，并标记 `substituted_from`。

#### 步骤 5：卷内排序

保持与真题一致：**按题型大题顺序**（选择→填空→解答），题型内按知识点章节顺序或题号顺序排布。

#### 步骤 6：落库快照

每道入卷题写入 `test_questions`：

- 复制 content / options / answer / analysis / images / score / primary_kp_id  
- 保留 `source_question_id` 溯源  
- 记录 `template_id`、`algorithm_version`、`lambda`、是否 degraded  

### 3.5 例算（帮助对齐理解）

假设：

- 真题模板：选择 10 题 ×4 分；用户已学 5 个知识点 \(k_1..k_5\)  
- 真题在选择题上占比：\(k_1:40\%,\ k_2:30\%,\ k_3:20\%,\ k_4:10\%,\ k_5:0\%\)（\(k_5\) 真题没考但用户已学）  
- \(\lambda=0.35\)，\(S_{choice}=40\)

则均匀项 \(40/5=8\) 分/点。对 \(k_1\)：

\[
G' = 0.65\times(40\times0.4) + 0.35\times 8 = 10.4+2.8=13.2 \Rightarrow m \approx 3\ \text{题}
\]

对 \(k_5\)（真题 0）：

\[
G' = 0 + 0.35\times 8 = 2.8 \Rightarrow m \approx 1\ \text{题}
\]

再经 Largest Remainder 调到总和 10 题。  
→ **既跟真题权重，又保证已学点都有机会出场。**

### 3.6 后台配套功能（本阶段要排期）

1. 题目批量关联知识点（含覆盖率仪表盘）  
2. 真题卷「生成/刷新结构模板」按钮  
3. 知识点/类别分值占比报表（按卷、按地区聚合）  
4. 测评实例列表：谁、何时、何目标、何模板、得分

## 5. 模块 4 — 阅卷批改

### 5.1 流程

```text
交卷 → 进入 grading
  → 选择题：自动比对标准答案
  → 填空题：规则归一化比对（去空格、同义写法表）+ 必要时 LLM 判分
  → 简答题纯文本：对照标准答案 LLM 采分点批改
  → 简答题含手写图：OCR（公式友好优先）→ 文本化 → 同上批改
  → 汇总得分、逐题对错、得分点明细 → graded
```

### 5.2 OCR 与批改原则

1. OCR 结果写入 `ocr_text`，保留原图；批改以 OCR+标准答案为准  
2. 解答题按 **采分点**（可从标准答案/解析拆解，或 LLM 生成后人工可改）给分，不全对不全错  
3. 低置信 OCR 标记 `needs_review`，学生端提示「手写识别可能不准」  

### 5.3 输出

- 每题：对错、得分、满分、批改说明（短）  
- 整卷：总分、正确率、分题型得分

## 6. 模块 5 — 错题讲解

### 6.1 规则

1. 错题优先展示题库快照中的 **analysis（解析）**  
2. 无解析时：用 LLM 基于题干+标准答案生成「待审草稿」，并打标  
3. 「还是不懂」→ 进入追问会话：注入  
   - 题目与解析  
   - 学生认知画像（能力维度、近期错因）  
   - 当前目标年级与已学范围  
4. 回答约束：不直接甩最终答案步骤剧透过度；按认知水平分层提示（思路→关键步→完整）

### 6.2 数据

- `WrongQuestionReview`、`TutorSession`、`TutorMessage`

## 7. 模块 6 — 能力诊断

### 7.1 诊断输出（学生画像增量）

| 维度 | 内容 |
|------|------|
| 知识点掌握度 | 每点 \(mastery\in[0,1]\)、置信度、上次测到时间 |
| 薄弱急学列表 | 结合目标分差距 + 真题占比 \(\pi(k)\) 加权的优先级 |
| 能力雷达 | 计算 / 记忆 / 理解 / 推理（映射自题目 `ability_dimension` 或知识点认知等级） |
| 优势点 | mastery 高且稳定的类别 |
| 本次测评报告 | 当次得分、分题型、分知识点正误 |
| 历史对比 | 近几次总分、薄弱点变化、进步率 |

### 7.2 掌握度更新（建议公式）

对知识点 \(k\)，当次相关题得分率 \(r\)（满分加权）：

\[
m_{new} = (1-\beta) m_{old} + \beta\cdot r
\]

- 首测 \(\beta=0.6\)；题少时降低 \(\beta\) 并降置信度  
- 急学分：\(priority(k)=(1-m_k)\cdot \pi_{template}(k)\cdot urgency\)  

### 7.3 展示

- 当次诊断页 + 历史趋势页  
- 明确「基于第 N 次测评」与「综合评估」两个 Tab

## 8. 模块 7 — 路径规划

> **可直接开发的详细方案**：[`学习路径生成-产品与技术设计.md`](./学习路径生成-产品与技术设计.md)

### 8.1 输入

- 激活目标（目标分、剩余时间、每日时长）  
- 多轮诊断形成的掌握分、置信度、作答次数与状态  
- 真题模板下的知识点分值权重  
- 前置依赖图谱与已稳定掌握集合

### 8.2 算法要点（首期可规则化）

1. 根据当前预估分与目标分计算需要弥补的分数差距。  
2. 综合掌握缺口、真题权重、预计提分、学习时长和依赖杠杆计算优先级。  
3. 选择单位时间收益较高的目标知识点，并补齐 **未稳定掌握的前置闭包**。  
4. 对关系环使用强连通分量折叠为知识簇，再执行带优先级的拓扑排序。  
5. 按考试剩余时间和每日时长切分为阶段与每日任务；时间不足时明确区分核心路径和暂缓内容。  
6. 输出可解释原因：「先学 A 因为是 B 的前置；B 真题权重高、当前掌握分低，预计贡献 X 分提升」。

### 8.3 输出

- `LearningPath`：带目标、画像和算法快照的版本化路径  
- `LearningPathNode`：有序知识点、阶段、优先级、预计提分与原因  
- `LearningTask`：日任务（概念 / 例题 / 练习 / 检查 / 复习）  
- `deferred_nodes`：因时间不足或收益较低暂缓的知识点  

### 8.4 重规划

- 新测评、目标分/章节变更、核心知识点掌握分显著变化时提示重规划。  
- 重规划生成新 draft，用户确认后切换；旧路径归档并保留完成记录。  
- 不允许系统静默覆盖学生正在执行的路径。

## 9. 模块 8 — 动态课程生成

### 9.1 结构

```text
课程（针对某 path 版本）
  └── 单元 Unit（通常 1 个知识点或小知识团）
        ├── 讲解资料（知识点库/预生成讲义）
        ├── 视频链接（公开平台 URL，后台可维护或检索缓存）
        └── 练习题（模拟题库 / 预生成练习，挂同一知识点）
```

### 9.2 资源优先级

1. 后台已审核讲义/视频  
2. 预生成练习卷（按知识点）  
3. 检索类视频链接（需来源白名单与备案字段）  
4. 缺失则标记「资源不足」并仍保留练习任务  

### 9.3 与题库关系

- 课程练习 **优先模拟题**；阶段测 **优先真题结构模板** 再组卷

## 13. 关键验收口径（产品）

1. 数学目标下，卷中题目均来自数学题库且主知识点 ∈ 已学集合（或合法降级并披露）  
2. 题型题量与指定真题模板一致（除非题源不足降级）  
3. 卷面知识点分值分布与 \(G'\) 配额误差可控（如题型内总分相对误差 ≤ 10%，或题数级 Largest Remainder 可解释）  
4. 每次测试后台可回看完整题目/答案/解析快照与批改结果  
5. 多目标互不覆盖；清真题库不影响模拟库（已有后台能力）

## 14. 待产品拍板的问题

1. 首测题源：**仅真题** 还是 **真题+模拟题** 混合？  
2. \(\lambda\)（真题占比 vs 均匀覆盖）默认 0.35 是否接受？  
3. 一题多分知识点时，分值是否一律归主知识点？  
4. 手写批改：P1 是否允许「仅 OCR+人工复核」过渡，还是必须全自动采分？  
5. 视频：只允许运营录入链接，还是允许运行时搜索？
