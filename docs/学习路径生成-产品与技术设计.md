# 学习路径生成——产品与技术方案（v2.7）

> **定位**：承接学习目标、多轮测评、知识点掌握度和知识关系图谱，为学生回答四个问题：接下来学什么、为什么学、先后顺序是什么、在可用时间内能达到什么程度。  
> **适用场景**：当前以“考试目标分”为主要目标类型；章节巩固、专题突破等其他目标可复用框架，但使用不同的目标价值函数。  
> **重要结论**：学习路径不是“薄弱知识点排行榜”，也不是“把所有可用时间填满”。它是在目标相关性、证据、前置关系和时间容量约束下，选择一组有明确收益的学习任务。  
> **实施状态（2026-07-31）**：`path-v2.7` 将当前版本严格限定为首轮学习规划，只纳入有充分当前测评证据的首次学习任务；证据不足知识点和后续强化不进入本轮任务、时长、预计提分与预计分数，完成首轮掌握检查和复测后再生成下一轮。

---

## 1. 核心设计原则

### 1.1 已学范围是认知范围，不等于路径候选

`learned_kp_ids` 的口径保持不变：

```text
当前年级阶段以前各册全部知识点
+ 当前册用户勾选章节的知识点
= 学生已经接触过、允许被诊断的认知范围 L
```

这个设计是正确的。例如九年级上册学生的认知范围应当包含七年级上册至八年级下册。

但必须区分：

- **认知范围**：哪些知识点允许出题、诊断和计算掌握度。
- **规划候选**：哪些知识点对当前目标确实有价值，允许进入学习路径。
- **最终路径**：在时间和依赖约束下真正安排的知识点。

三者关系为：

\[
最终路径 \subseteq 规划候选 \subseteq 已学范围L
\]

不得把整个 `learned_kp_ids` 直接当成路径候选。

### 1.2 先做硬性准入，再做软性排序

路径算法分两层：

1. **硬规则**决定知识点有没有资格进入候选池。
2. **软评分**只负责给已经合格的候选排序。

权重低、收益为零、没有测评证据、又不是必要前置的知识点，即使剩余时间充足也不能进入路径。

### 1.3 不为填满时间而安排无价值内容

可用时间是上限，不是必须完成的配额。

```text
没有更多有效候选
→ 提前结束规划
→ 剩余时间保留为复习、休息或后续动态调整空间
```

### 1.4 路径必须可解释、可复现、可审计

- 核心决策由确定性算法完成，不由 LLM 决定。
- 相同输入快照和相同算法版本必须产生相同结果。
- 每个节点必须保存准入原因、排序原因、依赖关系和预计收益。
- LLM 只能润色说明文字，不能改变候选、顺序和排期。

## 2. 输入数据

| 数据 | 来源 | 用途 |
|------|------|------|
| 目标分、考试日、每日时长 | `learning_goals` | 分差、容量、可达性 |
| 已学认知范围 \(L\) | `learned_kp_ids` | 规划边界 |
| 当前册勾选章节 | `goal_learned_chapters` | 当前学习上下文与展示 |
| 掌握分、置信度、作答证据 | 共享掌握度快照 | 判断缺口与证据质量 |
| 题目得分与知识点映射 | `test_questions/test_answers` | 直接测评证据 |
| 知识点考试权重 | `exam_kp_score_stats` | 估算目标价值 |
| 前置关系 | `knowledge_relations` | 强顺序与前置闭包 |
| 知识领域、章节、认知层次 | `knowledge_points` | 知识单元标签与学习时间估算 |
| 资源覆盖情况 | 题库、后续课程资源 | 学习成本与降级提示 |

### 2.1 规划快照

每次生成路径必须冻结：

- `goal_snapshot`
- `mastery_snapshot`
- `source_paper_ids`
- `template_id`
- `weight_snapshot`
- `relation_snapshot`
- `planning_params`
- `algorithm_version`

知识库或测评状态更新后生成新版本，不能静默改变旧路径的解释。

## 3. 第一步：统一当前认知状态

### 3.1 掌握度是唯一认知输入

路径规划直接复用认知地图的多轮掌握度：

- 综合所有历史作答。
- 越近的作答轮次权重越高。
- 直接作答与知识关系推断合并成一个掌握分。
- 同时输出置信度、直接作答次数、推断证据和最近趋势。

路径算法不得再维护第二套“已掌握/未掌握”判定。

### 3.2 风险修正掌握度

设：

- \(m_k\)：知识点掌握分，范围 0～1。
- \(c_k\)：置信度，范围 0～1。
- \(p_0=0.5\)：未充分测试时的中性先验。

\[
effectiveMastery_k=c_km_k+(1-c_k)p_0
\]

低置信度不会被直接当成“不会”，而是向 0.5 收缩。

### 3.3 当前预估分

规划使用知识点层面的综合估分，而不是机械采用最近一次卷面得分：

\[
knowledgeEstimate
=S_{total}\sum_k w_k\cdot effectiveMastery_k
\]

最近一次试卷得分只在以下条件满足时参与校准：

- 已完全批改；
- 与目标使用同一总分口径；
- 覆盖的考试权重达到设定阈值；
- 不是只有少量题的局部验证卷。

根据试卷覆盖度 \(coverage\) 进行融合：

\[
currentEstimate
=coverage\cdot recentPaperScore
+(1-coverage)\cdot knowledgeEstimate
\]

局部小测不能直接把当前估分拉到极低或极高。

## 4. 第二步：构造考试价值权重

### 4.1 权重来源优先级

1. 当前目标对应的正式考试结构模板；
2. 与目标相同地区、科目、考试类型的历史模板；
3. 学生目标测评中题目分值的知识点占比；
4. 同类别历史考试权重。

正式“提分路径”禁止直接回退为整个认知范围均匀权重。没有可靠权重时，应显示“考试价值数据不足”，生成诊断型路径或要求先补充测评。

### 4.2 权重不等于准入资格

考试权重是目标价值的重要证据，但不是唯一证据：

- 权重 \(>0\)：可作为直接目标候选。
- 权重为 0，但在目标测评中实际出现：使用该题分值形成经验权重。
- 权重为 0，且是已选核心节点的必要前置：可作为前置节点。
- 权重为 0、无直接测评、也不是必要前置：不得进入路径。

---

## 5. 第三步：候选知识点准入

### 5.1 数据完整性硬校验

知识点必须同时满足：

- `kp_id` 存在于知识点库；
- `subject == goal.subject`；
- 位于 `learned_kp_ids`；
- 名称、分类和章节字段可正常展示；
- 掌握度快照与权重快照使用同一个 `kp_id`；
- 没有被禁用、删除或标为异常数据。

不满足时记录数据告警，不进入路径。

### 5.2 直接目标候选

知识点必须满足以下全部条件：

1. 位于认知范围 \(L\)；
2. 未达到稳定掌握；
3. 对当前目标具有直接相关性；
4. 预计收益达到最低门槛。

直接相关性满足任意一项即可：

- 正式考试权重 \(w_k>0\)；
- 在目标相关测评中有直接作答；
- 属于用户明确选择的专题或章节目标；
- 被运营/教研标注为该目标的必学知识点。

### 5.3 待验证候选

未测试或低置信度知识点不能普遍加入路径。只有满足以下条件才能安排 `verify`：

- 权重处于目标范围较高分位，例如前 30%；或
- 是高价值知识点的必要前置；或
- 关系推断存在明显冲突，需要短测消歧。

验证任务本身不宣称预计提分，只计算信息价值。

### 5.4 前置候选

前置节点必须同时满足：

- 是某个已准入核心节点的直接或递归前置；
- 自身未稳定掌握；
- 去掉它会阻塞后继节点学习；
- 前置闭包深度不超过配置上限。

不能因为某个知识点“可能是别的内容的前置”，就把它单独塞进路径；它必须服务于本路径中已经选中的后继目标。

### 5.5 明确排除规则

满足任意一项直接排除：

- 稳定掌握：掌握分 ≥90 且置信度 ≥0.7；
- 权重为 0、无目标测评证据且不是必要前置；
- 预计提分小于最低阈值且没有依赖价值；
- 预计学习成本明显大于可获取收益；
- 缺少可靠资源且无法安排验证；
- 学科、章节或知识点 ID 不一致；
- 仅因为“还有剩余时间”。

## 6. 第四步：计算价值、成本和不确定性

### 6.1 目标掌握分

按考试价值和认知要求设置目标：

| 知识点类型 | 目标掌握分 |
|------------|------------|
| 高权重核心考点 | 85～90 |
| 中权重考点 | 78～85 |
| 低权重基础点 | 70～78 |
| 必要前置 | 达到足以解锁后继的 70～80 |
| 待验证 | 不预设学习目标，先验证 |

### 6.2 掌握缺口

\[
gap_k=\max(0,targetMastery_k-effectiveMastery_k)
\]

### 6.3 直接可恢复分

\[
directGain_k
=S_{total}\cdot w_k\cdot gap_k
\cdot learnability_k
\cdot transfer_k
\]

- `learnability`：在当前时间内可学会的概率。
- `transfer`：学会后迁移到考试题目的概率。
- 两者首期采用规则配置，后续用历史学习结果校准。

对于 `verify` 节点，`directGain=0`，另计 `informationValue`。

### 6.4 前置解锁价值

前置知识点即使自身权重较低，也可能因为解锁多个高价值后继而需要优先学习。只计算“当前目标相关、尚未掌握、且确实被该前置阻塞”的后继：

\[
unlockGain_p
=\sum_{t\in blockedDescendants(p)}
directGain_t
\cdot dependencyShare_{p,t}
\cdot 0.7^{distance(p,t)-1}
\cdot blockedFactor_t
\]

- `dependencyShare`：多个未满足前置共同解锁同一后继时，按关系强度分摊，避免每个前置都获得全部后继价值。
- `distance`：直接后继为 1；每远一层按 0.7 衰减。
- `blockedFactor`：确实阻塞取 1，证据不足取 0.5，后继已掌握或不属于本次目标取 0。
- 不能按“后继数量”直接加分；只累计后继的目标价值。
- `unlockGain` 只用于排序与解释，路径总预计提分仍只汇总各节点的 `directGain` 一次，禁止重复计分。

### 6.5 学习成本

预计时间由以下因素组成：

- 知识点认知层次；
- 掌握缺口；
- 置信度；
- 历史同类任务完成时间；
- 可用题目和资源数量；
- 是否需要先验证。

\[
cost_k=baseMinutes_k
\cdot(0.65+gap_k)
\cdot(1+uncertaintyPenalty_k)
\]

预计时间必须限制在合理区间，并允许大任务拆分。

### 6.6 首轮边界与下一轮触发

当前路径版本只规划首轮，不提前承诺后续强化收益：

```text
首轮规划
→ 概念学习、针对练习、掌握检查
→ 首轮复测并形成新的有效作答数据
→ 更新掌握度、置信度、学习成功率与迁移率
→ 生成下一轮规划
```

- 本轮只纳入已有充分当前测评证据、能够计算首次学习直接收益的知识点；
- 掌握情况数据不足的目标相关知识点留到下一轮，不生成本轮验证节点；
- 后续强化是否需要、需要几轮以及可提多少分，必须在首轮复测后重新计算；
- 本轮任务、预计时长、预计提分和预计分数均不得包含强化层级或强化假设；
- 黄色规划说明必须展示首轮预计完成日期、首轮预计提分、提分受限原因、下一轮触发条件；如受时间容量限制，还必须说明未排入知识点数量并给出增加每日投入或延长周期的建议。

### 6.7 边际效用

知识点的排序价值为：

\[
strategicValue_k
=directGain_k
+\alpha\cdot unlockGain_k
+\beta\cdot informationValue_k
\]

实际选择按目标知识点 \(t\) 与其尚未纳入的必要前置组成增量包 \(B_t\)：

\[
utility(B_t)=
\frac{
\sum_{k\in B_t}directGain_k
+\alpha\cdot frontierUnlockGain_t
+\beta\sum_{k\in B_t}informationValue_k
}{
\sum_{k\in B_t}incrementalCost_k
}
\]

其中：

- 核心节点主要看 `directGain`；
- 前置节点主要看 `unlockGain`；
- `informationValue` 保留为下一轮诊断候选的内部价值，不进入当前首轮正式路径；
- 诊断信息价值表示“补测后减少认知不确定性、帮助决定后续是否补学”的排期价值，当前实现为：

\[
informationValue_k
=totalScore\cdot examWeight_k\cdot(1-confidence_k)\cdot0.2
\]

- `informationValue` 不是分数，不得计入知识点、阶段或整条路径的预计提分；
- `frontierUnlockGain` 只计算增量包完成后新增的最下游前沿节点；同一后继沿一条前置链只计一次，禁止把同一收益在每层前置上重复累加；
- 已经被其他节点共用并纳入路径的前置，不重复计算时间；
- 建议首期 \(\alpha=0.7\)，后续根据真实学习与复测结果校准；
- 三种价值必须分开保存，前端不能把验证价值显示成预计提分。

预计提分采用唯一的逐级汇总口径：

```text
知识点首轮预计提分 = 首轮直接提分
阶段首轮预计提分 = Σ 阶段内知识点首轮预计提分
路径首轮预计提分 = Σ 各阶段首轮预计提分
```

保守值与乐观值分别按同一层级求和。后续强化、后继解锁价值和诊断信息价值均不参与上述求和。

## 7. 第五步：目标可达性评估

在选择路径前先计算：

- 当前预估分；
- 目标分差；
- 可用总时间；
- 所有合格候选在容量内的保守收益；
- 乐观收益上限。

可达性分类：

| 状态 | 判断 | 页面表达 |
|------|------|----------|
| `reachable` | 保守预计提升足以覆盖分差 | 按目标生成路径 |
| `tight` | 保守值不足，但乐观值可能覆盖 | 提示目标较紧，需要较高完成率 |
| `insufficient` | 乐观值也无法覆盖分差 | 明确显示当前周期不可达 |
| `maintain` | 当前估分已经达到目标 | 生成复习保持路径 |

不能因为目标不可达就继续塞入低价值知识点。目标不可达时仍生成“当前条件下最优核心路径”，同时给出：

- 预计能达到的分数区间；
- 还缺多少时间；
- 延长周期或增加每日时长后的模拟结果；
- 被暂缓的内容及原因。

---

## 8. 第六步：在容量内选择核心路径

### 8.1 可用容量

\[
capacity
=availableDays\cdot dailyMinutes\cdot(1-bufferRatio)
\]

默认保留 20% 用于复习、突发延期和阶段检测。

### 8.2 带依赖成本的选择

对每个核心候选计算：

```text
增量成本
= 候选自身成本
+ 尚未纳入且未稳定掌握的必要前置成本
```

采用可复现的约束贪心或小规模背包算法：

1. 过滤所有不合格候选；
2. 计算候选的前置闭包和增量效用；
3. 选择边际效用最高的候选及其必要前置；
4. 更新已选集合、容量和剩余候选；
5. 重算边际效用；
6. 满足停止条件后结束。

### 8.3 必须执行的停止条件

满足任意一项立即停止：

- 已达到目标分差所需的保守收益；
- 剩余容量不足；
- 剩余候选 `directGain`、`unlockGain`、`informationValue` 均低于门槛；
- 所有剩余候选的单位时间收益低于最低阈值；
- 没有更多满足硬性准入规则的候选。

**禁止用零收益知识点填充剩余时间。**

### 8.4 暂缓清单

未被选择的合格候选进入 `deferred_nodes`，记录：

- 时间不足；
- 收益较低；
- 前置成本过高；
- 证据不足；
- 资源不足。

被硬规则排除的知识点不进入暂缓清单，避免让学生误认为“以后一定要学”。

---

## 9. 第七步：依赖排序与价值阶段

### 9.1 依赖顺序

只有 `relation_type=prerequisite` 是强顺序约束：

1. 递归补齐已选核心节点的薄弱前置；
2. 稳定掌握的前置视为已满足，不生成任务；
3. 使用强连通分量识别循环依赖；
4. 循环依赖折叠为同一知识簇；
5. 对知识簇 DAG 执行拓扑排序。

### 9.2 阶段以二级分类为最小粒度

同一 `category_2` 下的知识点必须进入同一阶段，不同二级分类不得混入同一阶段。系统先计算每个知识点的首轮价值：

```text
首轮战略价值 = 首轮直接提分 + α × 后继解锁价值 + β × 诊断信息价值
首轮边际价值 = 首轮战略价值 ÷ 首轮预计学习时间
```

再汇总二级分类整体价值：

```text
分类战略价值 = Σ 分类内知识点首轮战略价值
分类边际价值 = 分类战略价值 ÷ Σ 分类内知识点首轮预计学习时间
```

然后按以下规则生成阶段：

1. 将知识点按 `category_1 + category_2` 聚合，二级分类相同且一级分类相同才属于同组；
2. 缺少 `category_2` 的知识点各自单独成组，禁止把所有空分类合并；
3. 分类间存在前置关系时，前置分类必须早于后继分类；
4. 当前已满足前置条件的分类，按分类边际价值从高到低排列；
5. 同一分类内部继续按知识点边际价值排序，并满足内部前置关系；
6. 每个二级分类对应一个阶段，阶段可以跨多个学习日。

推荐结构：

```text
阶段 1：二级分类 B（分类边际价值最高）
  ├── 知识点 B1
  └── 知识点 B2

阶段 2：二级分类 A（分类边际价值次高）
  ├── 知识点 A1
  └── 知识点 A2
```

即使两个知识点都具有高收益，只要不属于同一二级分类，也不能进入同一阶段。

### 9.3 阶段命名

阶段名称直接使用二级分类名称；缺少二级分类时使用“未设置二级分类 · 知识点名称”。

## 10. 第八步：切分日任务

### 10.1 任务模板

| 节点角色 | 任务组合 |
|----------|----------|
| `verify` | 5～10 分钟短测 → 根据结果决定退出或转学习 |
| `prerequisite` | 核心概念 → 基础例题 → 解锁检查 |
| `remediate` | 概念纠错 → 分层例题 → 针对练习 → 掌握检查 |
| `strengthen` | 易错复盘 → 迁移练习 → 掌握检查 |
| `maintain` | 间隔复习 → 综合复测 |

### 10.2 排期约束

- 每日任务总时长不超过设定时长的 100%，除非用户显式允许弹性。
- 每日新知识点不超过 3 个。
- 每日尽量不跨超过 2 个一级领域。
- 前置检查未通过，后继任务保持 `blocked`。
- 每 5～6 个学习日安排复习或缓冲。
- 路径可以没有填满每日时间。

### 10.3 验证任务分支

验证结果必须动态分流：

```text
验证通过
→ 不再安排该知识点学习
→ 释放时间重新规划

验证未通过
→ 转为 remediate
→ 生成概念、练习和检查任务
```

因此验证任务不能在生成时直接计入预计提分。

## 12. 用当前问题做回归示例

规划条件：

- 当前估分 3.3；
- 目标分 120；
- 2 天；
- 每天 150 分钟；
- 缓冲后容量约 240 分钟。

### 12.1 集中趋势度量

- 掌握分约 32.1；
- 1 对、2 错；
- 有考试权重；
- 有直接测评证据；
- 预计收益大于最低门槛。

结论：可以进入核心候选。

### 12.2 估计无理数

- 掌握分约 18.2；
- 0 对、2 错；
- 有考试权重；
- 有直接测评证据；
- 预计收益大于最低门槛。

结论：可以进入核心候选。

### 12.3 离散程度度量

- 尚未直接测试；
- 置信度为 0；
- 当前模板权重为 0；
- 不是已经选中核心节点的必要前置；
- 预计直接提分为 0。

结论：必须排除，不能因为还剩 52 分钟就加入路径。

### 12.4 阶段组织

如果前两个知识点不属于同一二级分类，必须拆成两个阶段，并按分类边际价值排序：

```text
阶段 1：二级分类 A
  └── 集中趋势度量

阶段 2：二级分类 B
  └── 估计无理数
```

不能把二者描述为存在知识依赖，也不能给阶段起一个暗示它们属于同一知识主题的名称。

由于预计提升远小于 116.7 分，页面必须提示：

> 当前 2 天、每天 150 分钟的条件下，目标 120 分不可达。本路径仅保留单位时间收益最高的核心内容，建议增加学习周期、调整每日投入或重新评估目标。

## 16. 页面设计

### 16.1 路径概览

- 当前估分、目标分、分差；
- 可用时间和缓冲时间；
- 保守/乐观预计提升；
- 可达性结论；
- 数据质量提示；
- 调整每日时长或规划周期后的即时模拟。

### 16.2 核心路径

- 价值阶段；
- 二级分类；
- 知识点顺序；
- 当前掌握分、目标掌握分；
- 直接收益、解锁价值或验证价值；
- 为什么安排、为什么排在这里。

### 16.3 暂缓内容

只展示曾通过候选准入、但受容量或成本限制未被选择的知识点。

### 16.4 不可达提示

目标不可达时不得只显示一个乐观数字，应突出：

- 当前条件下预计达到的分数区间；
- 目标还差多少；
- 推荐延长多少天或增加多少每日时长；
- 本轮仍值得完成的核心路径。

## 17. 降级策略

| 问题 | 正确处理 |
|------|----------|
| 无正式考试权重 | 回退目标测评实际分值占比；仍无数据则生成诊断路径，不均匀分配正式提分权重 |
| 无直接测评 | 仅对高价值点或必要前置安排验证 |
| 前置关系缺失 | 按教材顺序排列并标记关系数据不足 |
| 存在循环依赖 | SCC 折叠为知识簇 |
| 时间不足 | 生成最优核心路径并明确不可达 |
| 没有有效候选 | 返回“暂无值得优先安排的知识点”，不填充时间 |
| 数据 ID 不一致 | 排除节点并产生数据质量告警 |
| 资源不足 | 暂缓或只安排验证，不虚构可执行任务 |

## 18. 测试与验收

### 18.1 候选准入

1. `learned_kp_ids` 中权重为 0、无证据、非前置的节点不得进入路径。
2. 权重为 0但属于核心节点必要前置的节点可以进入。
3. 未测试普通节点不得批量生成验证任务。
4. 学科或 ID 不一致节点必须被排除并告警。

### 18.2 排序与依赖

1. 必要前置始终早于后继。
2. 已稳定掌握前置不重复安排。
3. 相同收益下优先学习成本更低者。
4. 循环依赖能够折叠，不死循环。
5. 同一输入结果稳定。

### 18.3 容量与停止

1. 任务总时长不超过容量。
2. 无有效候选时允许剩余时间为空。
3. 预计收益为 0的普通节点永不用于填充容量。
4. 达到收益目标后停止继续选点。
5. 不可达目标必须返回 `insufficient`。

### 18.4 阶段与展示

1. 每个二级分类对应一个阶段，同分类不拆分、不同分类不混组。
2. 阶段在满足分类间前置关系后，按分类整体边际价值降序。
3. 验证价值不能显示成预计提分。
4. 每个节点都能回答“为什么选它”和“为什么现在学”。

### 18.5 本次缺陷回归

固定使用以下回归案例：

- 集中趋势度量：有权重、有错题证据，应进入候选。
- 估计无理数：有权重、有错题证据，应进入候选。
- 离散程度度量：零权重、未测试、非必要前置，不得进入路径。
- 前两者若不属于同一二级分类，必须进入不同阶段，并按分类整体边际价值排序。

## 21. 最终决策规则

一个知识点进入路径前，系统必须依次回答：

```text
1. 它属于该学生的已学认知范围吗？
2. 它和当前目标有直接关系，或是必要前置吗？
3. 有足够证据说明需要学或需要验证吗？
4. 它具有直接收益、解锁价值或信息价值吗？
5. 在加入全部必要前置后，单位时间价值仍然合理吗？
6. 它能在时间容量内完成吗？
7. 它应该属于哪个依赖阶段和知识主题？
```

只要前六个问题中有一个无法给出合理答案，该知识点就不能进入正式路径。
