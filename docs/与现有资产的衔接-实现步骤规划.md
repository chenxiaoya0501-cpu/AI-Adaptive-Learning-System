# 与现有资产的衔接 — 实现步骤（精简版）

> 依据：`与现有资产的衔接-产品与技术方案.md`  
> 范围：**仅后台 Admin 资产能力**；学生端勾选/目标设定等不在本衔接范围内。

---

## 先看懂目标

```text
现在：有知识点、有题目，但题和点没绑牢；没有规范的教材章节目录；没有真题结构统计
目标（衔接完成）：题挂好知识点 + 教材章节目录可抽取可查看 + 真题模板可统计 + 能组卷快照
```

分三层，按顺序做：

| 层级 | 一句话 |
|------|--------|
| **基础** | 题挂知识点；从课本抽出章节目录并展示 |
| **核心** | 真题结构模板；组卷并快照 |
| **增强** | LLM 批改/追问等（可后做） |

---

## 一、基础

### 第 1 步：题目关联主知识点（人工 + 大模型）

**目标**：每道题有一个「主知识点」；真题卷挂载率尽量 ≥ 90%。

#### 1.1 字段与规则

| 项 | 说明 |
|----|------|
| 主知识点 | `primary_kp_id`（必填才算「已挂载」） |
| 次要知识点 | 可选，多个，不影响组卷计分归属 |
| 组卷规则 | 无主知识点的题 **不进组卷池** |
| 候选范围 | 仅 `published`（过渡期含 `reviewed`）的知识点 |

#### 1.2 两种挂载方式

**A. 大模型批量关联（主路径）**

```text
数学题库页 →「批量智能关联」
  → 选题范围（某套试卷 / 全部未挂载 / 已勾选）
  → 后台任务：题干(+选项)与知识点列表交给 LLM
  → 每题返回：主知识点 ID + 置信度 + 简短理由
  →「待确认」列表（不直接落库）
  → 运营确认 / 改选后保存
```

- **入口固定**：只在 **数学题库** 页点「批量智能关联」创建任务（不放进「知识抽取」）  
- 分批调用，进度可查；失败可重跑未完成部分  

**B. 手动修改（纠错 / 补挂）**

- 单题编辑：下拉或搜索选择知识点（显示名称，不只填 ID）  
- 批量：表格内直接改主知识点，或勾选多题统一指定一个点  

#### 1.3 界面交互（数学题库）

**题目列表增加**

| 元素 | 作用 |
|------|------|
| 筛选「挂载状态」 | 全部 / 已挂载 / 未挂载 / 待确认（LLM 已建议未保存） |
| 筛选「按试卷」 | 盯一套真题看挂载率 |
| 列「主知识点」 | 显示知识点名称；空显示「未挂载」标红 |
| 顶部按钮「智能关联」 | 对当前筛选结果或勾选行启动 LLM 批量任务 |
| 顶部「挂载率」 | 如：本卷 22/24（92%） |

**智能关联流程（弹窗）**

```text
1. 范围：当前试卷 / 仅未挂载 / 已勾选的 N 题
2. 点击「开始关联」→ 出现任务进度（可跳转任务列表）
3. 完成后打开「确认结果」抽屉：
   ┌ 题干摘要 │ 建议主知识点 │ 置信度 │ 操作 ┐
   │ 17.抛物线… │ 二次函数·图象 │ 高    │ [采用][改选] │
   └──────────────────────────────────────────┘
4. 支持「全部采用高置信」「逐条改选后保存」
5. 保存后列表刷新，挂载率更新
```

**单题手动改**

- 点编辑 →「主知识点」用 **可搜索下拉**（按名称/分类搜，不要只填 ID）  
- 详情页同样展示名称，可一键跳转编辑  

**试卷管理行（可选）**

- 显示该卷「已挂载/总题数」；未达标标黄，方便运营优先处理真题卷  

#### 1.4 完成标准

- 打开一套真题，几乎每道题都有主知识点名称  
- 能筛出未挂载题；能跑一遍智能关联并人工确认改掉错绑  

#### 1.5 不做

- 不自动、无确认地全库覆盖写入（避免 LLM 误绑难追回）  
- 学生端不参与挂载  

### 第 2 步：章节目录抽取与展示（Admin）

**抽取**（放在「知识抽取」）：

- 新建任务类型：**章节目录抽取**
- 选择已上传的**教材 PDF**（资料上传里已有）
- 复用现有章/节识别（`chunk_textbook_pdf` 同类逻辑），后台任务跑完入库

**展示**（知识图谱管理下新子栏目「章节目录」）：

- 按教材 / 年级 / 册查看已抽取的章、节列表
- 支持改名、删噪、排序后保存
- 可显示每章关联知识点数（与 KP 的 `chapter` 匹配，有则显示）

```text
资料上传（教材 PDF）
    → 知识抽取 · 任务类型「章节目录抽取」
    → 章节目录页查看 / 编辑结果
```

**菜单**：

```text
知识图谱管理
  · 图谱概览
  · 知识点管理
  · 关系管理
  · 资料上传
  · 知识抽取          ← 增加任务类型「章节目录抽取」
  · 章节目录          ← 新增：只负责展示与编辑目录
```

**完成标准**：对一本教材跑完「章节目录抽取」后，在「章节目录」页能看到完整章列表并可编辑保存。

**不做**：学生端勾选已学章节（不属于本衔接范围）。

## 二、核心

### 第 3 步：真题结构模板

> 产品方案详见：[真题结构模板-产品方案.md](./真题结构模板-产品方案.md)

- 补分值（或默认分值表）
- **运营勾选一套或多套真题**，统计题型题量与知识点分值占比，存为模板并可设默认

**完成标准**：勾选真题后能生成模板，看到选择/填空各几道、各知识点大致占分，并能设默认。

### 第 4 步：组卷 + 快照

- 用已挂知识点的题 + 模板组卷，整卷快照落库

**完成标准**：一次组卷接口能出结构接近真题的卷，且改题库不影响已存快照。

## 不要做什么

- 本阶段不做学生端勾选章节  
- 不复制第二套题库/知识点库  
- 不在「资料上传」行上塞提取按钮（提取统一走知识抽取任务）
