# 中考数学 AI 自适应学习系统 — 产品设计概述

> **文档性质**：产品/需求总览（开发可参考的架构级需求文档）  
> **版本**：v0.1  
> **状态**：架构与模块边界确认稿（各模块细节另文细化）  
> **范围**：学生端 + 后台管理系统；学科首期仅数学，架构预留多学科扩展  

---

## 1. 产品定位

### 1.1 一句话定位

面向中考生个人的 **AI 自适应学习操作系统（AI Learning OS）**：根据学生目标与当前认知状态，动态规划学习路径、组织知识、生成教学内容与练习，以最高效率完成数学认知升级。

### 1.2 产品原则

| 原则 | 说明 |
|------|------|
| 目的导向 | 先有中考目标与时间约束，再组织学习 |
| 状态驱动 | 路径与内容依赖能力画像，而非固定课表 |
| 动态组织 | 不做静态课程售卖；按「当下最有价值」组装知识与任务 |
| 闭环优化 | 学练评后更新画像，持续重规划 |
| 可解释 | 学生能理解「为什么学这个」 |
| 学科可扩展 | 首期数学（浙江中考 / 浙教版优先），知识资产与 Agent 按学科插件化预留 |

### 1.3 明确不做（本期）

- 教师端、学校/机构端、班级管理
- 家长独立 App（如后续需要，以只读报告形态另议）
- 全科同时上线（仅预留扩展点）

### 1.4 用户与系统边界

| 角色 | 使用系统 | 核心诉求 |
|------|----------|----------|
| 学生 | 学生端 | 明确目标 → 知道学什么 → 学懂 → 练对 → 看到进步 |
| 运营/教研/管理员 | 后台管理系统 | 配置考纲与图谱、题库与资源、监控生成质量与学习数据、用户与系统运维 |

## 2. 核心业务闭环

```text
目标设定
    ↓
能力诊断
    ↓
学习规划（学习规划 Agent）
    ↓
学习地图 / 每日任务
    ↓
动态课程生成 + AI Tutor 辅导 + 智能练习
    ↓
效果评估
    ↓
更新学生画像
    ↓
重新规划 ────────────────────────┘
```

系统价值不在「内容库存」，而在 **判断「什么知识对当下的该生最有价值」并完成组织与交付**。

## 4. 分层说明

| 层级 | 职责 | 开发关注点 |
|------|------|------------|
| **应用层** | 学生端交互；后台配置与运营 | 页面/API、权限、体验流程 |
| **AI 引擎层** | 规划、生成、辅导、评估、知识组织 | Agent 职责边界、调用编排、可回放 |
| **知识资产层** | 图谱、考纲、题库、资源、画像 | 数据模型、版本、学科隔离 |
| **基础层** | 接入加工、模型与中间件 | 管道、RAG、监控、成本与安全 |

## 5. 学生端功能模块

> 以下仅定义 **模块职责与边界**；字段级、交互级、接口级需求在后续分册细化。

### 5.1 目标设定中心

| 项 | 说明 |
|----|------|
| **定位** | 建立个性化学习起点：中考数学目标 + 时间约束 |
| **大致功能** | 目标分数设定；当前成绩/预估分录入；每日可学习时长与考试倒计时；目标拆解为可跟踪的阶段目标；目标变更触发重规划 |
| **主要输出** | 学生目标模型（目标分、剩余天数、每日预算、约束） |
| **边界** | 不做升学志愿复杂决策；首期仅数学目标（总分目标可预留字段） |

### 5.2 能力诊断中心

| 项 | 说明 |
|----|------|
| **定位** | 识别当前知识水平、薄弱点与错误类型 |
| **大致功能** | 入学/阶段测评；知识点掌握度评估；薄弱点识别；错误类型分析（概念/审题/计算/方法/迁移等）；诊断报告展示 |
| **主要输出** | 学生数学能力画像（分模块掌握度、薄弱列表、错因分布、置信度） |
| **边界** | 诊断服务引擎层评估 Agent + 题库；学生端负责施测 UI 与结果呈现 |

### 5.3 学习地图中心

| 项 | 说明 |
|----|------|
| **定位** | 将目标与能力差距转化为可见、可执行的动态路线 |
| **大致功能** | 阶段规划展示；知识依赖与解锁关系；每日/本周任务列表；学习进度与完成状态；路径动态调整结果展示；任务「为何推荐」的简要解释 |
| **主要输出** | 学习地图视图 + 当日任务清单（来自学习规划 Agent） |
| **边界** | 不在此模块内生成完整讲义；任务点击进入动态课程/练习/Tutor |

### 5.4 动态课程中心

| 项 | 说明 |
|----|------|
| **定位** | 按「缺什么补什么」组装个人课程，而非固定班课目录 |
| **大致功能** | 基于画像 + 图谱 + 资源生成个性化学习单元；单元结构建议含：概念学习 → 典型例题 → 变式 → 检测；课程推荐与单元详情；学习进度记录 |
| **主要输出** | 个人课程/学习单元（结构化内容流） |
| **边界** | 内容由课程生成 Agent 生产；人工精品资源可被匹配引用；超纲与事实错误依赖质检策略 |

### 5.5 AI Tutor 智能导师

| 项 | 说明 |
|----|------|
| **定位** | 学习过程中的实时陪伴辅导 |
| **大致功能** | 知识点解释；学习答疑；解题思路引导（多级提示）；错题分析与方法指导；结合当前任务上下文的对话 |
| **主要输出** | 辅导会话记录（可回流错因与理解状态） |
| **边界** | 不做无关闲聊主场景；回答应锚定考纲知识点与当前学习单元 |

### 5.6 智能练习中心

| 项 | 说明 |
|----|------|
| **定位** | 练「最有利于当前能力提升」的题，而非盲目刷量 |
| **大致功能** | 智能选题与分层训练；练习作答与即时反馈；错题本与错题归因；针对薄弱点的强化训练；与路径任务联动 |
| **主要输出** | 练习记录、错题集、掌握度更新事件 |
| **边界** | 选题策略由规划/评估引擎驱动；题面来自题库或受控生成 |

### 5.7 学习成长报告

| 项 | 说明 |
|----|------|
| **定位** | 持续反馈效果，支撑动机与下一阶段决策 |
| **大致功能** | 知识掌握度变化；能力提升趋势；学习时长/效率类指标；薄弱改善情况；下一阶段学习建议 |
| **主要输出** | 周期报告（日/周/阶段）与建议摘要 |
| **边界** | 报告数据由评估分析 Agent 汇总；不做社交排行榜（首期） |

### 5.8 账户与学习设置（支撑模块）

| 项 | 说明 |
|----|------|
| **定位** | 学生使用系统的基础账户与偏好 |
| **大致功能** | 注册登录；基本资料；地区/教材版本（如浙教版）；通知与学习提醒偏好；隐私与数据相关设置 |
| **边界** | 权限模型简单（学生角色）；复杂运营配置在后台 |

## 6. 后台管理系统功能模块

> 后台服务 **内容资产、策略配置、质量与数据**，不直接替代学生闭环中的学习决策，但为引擎提供可运营的「弹药」与管控。

### 6.1 用户与权限管理

| 项 | 说明 |
|----|------|
| **大致功能** | 管理员账号；角色权限（超管/运营/教研/只读分析等）；学生用户查询、状态管理（启用/禁用）；操作审计日志 |
| **边界** | 首期无教师组织树 |

### 6.2 学科与考纲配置

| 项 | 说明 |
|----|------|
| **大致功能** | 学科开关（数学启用，其它预留）；地区/考试类型（浙江中考）；考纲版本、题型结构、分值与能力要求配置；生效版本管理 |
| **边界** | 学生端只读生效配置 |

### 6.3 知识图谱管理

| 项 | 说明 |
|----|------|
| **大致功能** | 知识点 CRUD；层级结构（章节/考点/能力点）；前置依赖边；标签（考频、难度、教材章节映射）；导入导出与版本发布 |
| **边界** | 图谱质量直接影响规划；变更需可回滚 |

### 6.4 题库与试卷管理

| 项 | 说明 |
|----|------|
| **大致功能** | 题目录入/导入；知识点/难度/题型/来源标签；答案与解析；真题卷与专项卷组织；用于诊断/练习/模考的组卷规则配置 |
| **边界** | AI 生成题需进入审核流后方可入库（策略可配置） |

### 6.5 课程与资源管理

| 项 | 说明 |
|----|------|
| **大致功能** | 讲义、视频、图片、公式素材等资源管理；与知识点绑定；可供课程生成 Agent 检索匹配的资源池 |
| **边界** | 动态课程可以「生成 + 引用资源」混合，不要求全部人工录课 |

### 6.6 生成内容审核与质检

| 项 | 说明 |
|----|------|
| **大致功能** | 对 AI 生成的讲解、题目、解析抽检/审核；错误标记与下架；质检规则（超纲、答案不一致、格式等）；反馈样本用于改进 |
| **边界** | 与学生端举报/「讲错了」入口联动 |

### 6.7 学习数据分析

| 项 | 说明 |
|----|------|
| **大致功能** | 学习活跃、任务完成、掌握度分布、高频薄弱点、Tutor 会话与练习效果等聚合分析；支持教研看「哪些点普遍不会」 |
| **边界** | 首期以运营分析为主，不做对外商业报表 |

### 6.8 系统配置与任务运维

| 项 | 说明 |
|----|------|
| **大致功能** | 模型与 Agent 参数配置；提示词/策略版本；异步任务（解析、向量化、报告生成）状态；基础开关与限流；日志与告警查看入口 |
| **边界** | 基础设施细节可随技术选型调整，产品需保留「可配置、可观测」要求 |

## 7. AI 智能学习引擎层（逻辑模块）

> 引擎层可对内拆服务，对外通过应用层 API 暴露能力。模块名为逻辑边界，不强制进程拆分。

| 模块 | 大致职责 | 主要输入 | 主要输出 |
|------|----------|----------|----------|
| **学习规划 Agent** | 分析目标与能力差距；生成/调整阶段路径与每日任务；价值排序 | 目标模型、画像、图谱、时间预算 | 学习地图、任务队列、重规划事件 |
| **课程生成 Agent** | 按任务组织个性化课程内容；匹配资源；生成练习任务骨架 | 任务、画像、图谱、资源库 | 学习单元内容结构 |
| **AI Tutor Agent** | 实时讲解、答疑、思路引导、错因说明 | 对话上下文、当前知识点/题目、画像 | 辅导回复、结构化错因标签 |
| **评估分析 Agent** | 测评与练习后的掌握度更新；薄弱识别；报告与建议 | 作答记录、历史画像、考纲权重 | 更新后画像、报告数据、建议 |
| **知识组织 Agent** | 维护知识体系一致性；关联检索；支撑 RAG 与规划可用的知识视图 | 图谱、题库、资源元数据 | 检索结果、关联子图、一致性校验 |

**编排原则（概要）**：

- 规划 Agent 是路径决策中枢；课程 / Tutor / 练习服从当前任务上下文。
- 评估 Agent 写回画像后，应能触发规划 Agent 的增量或全量重规划。
- 所有生成应带 **学科 + 考纲版本 + 知识点 ID** 约束，避免游离内容。

## 10. 端到端关键用户旅程（开发对齐用）

### 10.1 学生首次使用

1. 注册登录 → 选择地区/教材（默认浙江 / 浙教版数学）  
2. 目标设定中心：目标分、当前水平、每日时长  
3. 能力诊断中心：入学测评 → 生成初始画像  
4. 学习规划 Agent 生成学习地图与首日任务  
5. 进入动态课程 / 练习，需要时唤起 AI Tutor  
6. 评估更新画像；次日任务可能调整  

### 10.2 学生日常学习

1. 打开学习地图 / 今日任务  
2. 完成课程单元与练习  
3. 错题进入强化与 Tutor 复盘  
4. 查看成长报告中的变化与建议  

### 10.3 后台教研日常

1. 维护图谱与考纲版本  
2. 导入/审核题目与资源  
3. 抽检 AI 生成内容  
4. 查看薄弱点与学习数据，反哺标签与路径策略
